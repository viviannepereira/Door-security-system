# Door-security-system

### **overview:** 
A mini door alarm system with an Arduino.
It detects if a door opens with a tilt ball switch, then it triggers a flashing LED and buzzer. 
The alarm continues until a password is typed in. 
Adjacent python program detects if alarm is going off then displays its findings on a Pygame window via serial communication.

### **hardware:**
- arduino uno
- tilt ball switch
- LED
- 220 ohm resistor (for LED)
- buzzer
- membrane keypad (4x4)
- breadboard 
- male to male wires (x12)
- female to male wires (x2, for tilt ball switch)
